# Site de présentation de Ghelis Elyes

Site en ligne : https://elyes-ghelis.github.io

Site personnel demandé par mon maître de stage pendant ma période de formation en milieu professionnel à Nîmes Métropole, du 23 novembre au 18 décembre 2026. Il présente mon parcours scolaire, mes stages et mes compétences, et permet de télécharger mon CV et ma lettre de motivation.

Je suis en Terminale Bac Pro CIEL au lycée La Salle d’Alès.

## Fichiers

- `index.html` : la page de présentation
- `style.css` : la mise en forme
- `mentions-legales.html` : l’hébergeur et les données personnelles
- `CV_Elyes_Ghelis.pdf` et `Lettre_Motivation.pdf` : les documents à télécharger

## Technique

HTML et CSS, sans framework ni JavaScript. L’en-tête est en Flexbox, les listes avec l’année à gauche en CSS Grid, et une media query adapte la page aux écrans de moins de 600 px.

J’ai appris le HTML et le CSS avec le cours OpenClassrooms « Créez votre site web avec HTML5 et CSS3 ». J’ai construit ce site avec l’aide d’un assistant IA (Claude), qui a écrit et corrigé une partie du code à ma demande.

## Voir le site sur son ordinateur

Ouvrir le dossier dans VS Code, faire un clic droit sur `index.html`, puis « Open with Live Server ». Si on ouvre le fichier par un double-clic, le CV et la lettre s’ouvrent dans un nouvel onglet au lieu de se télécharger.
